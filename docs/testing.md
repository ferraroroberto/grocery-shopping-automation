# Tests and the pre-ship gate

- **`tests/`** — `pytest` suite (`test_*.py`: unit + FastAPI `TestClient` + a Playwright e2e that drives the real buttons) plus standalone smoke scripts (`smoke_*.py`, `automation_smoke_*.py`). Run `& .\.venv\Scripts\python.exe -m pytest`, or the whole pre-ship gate with `& .\scripts\verify-before-ship.ps1` (pytest, then the static ratchet: a duplicate block or an unused import/variable that is not in `.static-ratchet-baseline.json` fails it, so the existing debt can only go down; it needs Node for `jscpd` and `ruff` from `requirements.txt`, and a detector that cannot run fails as NOT CONFIRMED rather than passing). The e2e stubs the LLM hub by default; set `GROCERY_E2E_LIVE=1` (with the hub running) to exercise the real model. The e2e also feeds the design inventory: each test calls the vendored `surface(page, "<tab>.<surface>")` (`tests/e2e/_surface.py`) once its surface is open, a no-op unless fleet-config's `/design-review measure grocery-shopping-automation --e2e` sets `DESIGN_SURFACE_CAPTURE`; a new surface takes one call in the test that opens it.
