# Tests and the pre-ship gate

- **`tests/`** — `pytest` suite (`test_*.py`: unit + FastAPI `TestClient` + a Playwright e2e that drives the real buttons) plus standalone smoke scripts (`smoke_*.py`, `automation_smoke_*.py`). Run `& .\.venv\Scripts\python.exe -m pytest`, or the whole pre-ship gate with `& .\scripts\verify-before-ship.ps1` (pytest, then the static ratchet: a duplicate block or an unused import/variable that is not in `.static-ratchet-baseline.json` fails it, so the existing debt can only go down; it needs Node for `jscpd` and `ruff` from `requirements.txt`, and a detector that cannot run fails as NOT CONFIRMED rather than passing; then the docs ratchet: `README.md` past 40 KiB, or a new issue reference, dated heading or changelog heading in `README.md` or `docs/**/*.md` beyond `.docs-ratchet-baseline.json`, fails it, so docs state what is true now and history stays in git, PRs and issues; a scan that cannot complete fails as NOT CONFIRMED too; then the comment ratchet: a file's count of `#NNN` issue references inside comments rising above `.comment-ratchet-baseline.json` fails it, so decision history stays in git, PRs and issues rather than in comments, and existing debt can only go down; then the structure ratchet: a file over 1,000 lines, a function over 100, a directory over 40 modules, a `src/` module importing `app/`, or a root folder outside the shape and `extra_roots` in `.fleet.toml` fails it beyond `.structure-ratchet-baseline.json`, so oversized code can only shrink and new code goes where [`docs/layout.md`](layout.md) says; a tree that cannot be measured fails as NOT CONFIRMED). The e2e stubs the LLM hub by default; set `GROCERY_E2E_LIVE=1` (with the hub running) to exercise the real model. The e2e also feeds the design inventory: each test calls the vendored `surface(page, "<tab>.<surface>")` (`tests/e2e/_surface.py`) once its surface is open, a no-op unless fleet-config's `/design-review measure grocery-shopping-automation --e2e` sets `DESIGN_SURFACE_CAPTURE`; a new surface takes one call in the test that opens it.
